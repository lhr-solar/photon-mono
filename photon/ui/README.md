# photon-frontend

Dear ImGui + ImPlot WASM client for photon-next. Speaks protocol v1 against
`photon-backend` on `ws://127.0.0.1:8765`.

See the **Frontend** section of the repo [README](../README.md) for exact
build / serve / demo commands and pinned versions.

```
emsdk 6.0.7   imgui v1.92.9-docking   implot v0.17   SDL2 port + WebGL2
```
